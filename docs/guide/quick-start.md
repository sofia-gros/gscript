# はじめのプログラム

このページでは、値を受け取って返す小さなプログラムを書き、GSの実行開始と型検査を確認します。導入済みの`gs`コマンドと、生成したJSを動かすNode.jsを使います。

## ファイルを作る

`hello.gs`というファイルに保存します。

```gs
func twice(value int) int {
  return value * 2
}
answer := twice(21)
println(answer)
```

`value int`はint型の引数、`) int`はint型の戻り値です。`:=`は右辺から型を推論して変数を宣言します。ここではanswerもintになります。

## コンパイルして実行する

```sh
gs hello.gs --format mjs --out-dir dist
node dist/hello.mjs
```

出力:

```text
42
```

GSファイルの文はトップレベルから実行されます。Goと違い、`main`という名前の関数は自動では実行されません。

## 型を間違えるとどうなるか

`twice(21)`を`twice("21")`へ変えると、文字列はintに渡せないためコンパイルエラーになります。生成したJSを実行する前に、GSコンパイラが不一致を見つけます。

# 変数と値

プログラムでは値に名前を付け、その名前を使って計算します。このページでは、再代入できる変数と再代入できない束縛を使い分けます。

## コメントと文の区切り

`// 行コメント`と`/* 複数行コメント */`を使用します。文は改行または`;`で区切ります。ブロックは`{ ... }`です。


## リテラル

文字列は`"text"`または`'text'`、真偽値は`true` / `false`、null値は`nil`、未定義値は`undefined`です。文字列にエスケープを使えます。数値は10進整数・小数・指数表記です。JSのバッククォート補間、Goのrune型、BigIntリテラルはありません。


## 変数と定数

```gs
var count int = 3
var name = "GS"
message := "Hello"
const limit = 10
var zero int
println(count, name, message, limit, zero)
```

`var`（`let`も使用可能）は変数、`const`は再代入できない束縛、`:=`は推論した型で新しい変数を宣言します。`var zero int`は0で初期化します。`const`は参照する配列やオブジェクトまで深く凍結しません。Goの複数値代入や複数戻り値の仕様をそのまま持つわけではありません。

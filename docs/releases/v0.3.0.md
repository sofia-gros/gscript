# GS 0.3.0

GS compiler release with checked local modules and selectable JS, MJS and
TypeScript output. `.gs` is the primary source extension; `.gos` remains supported.

## Compiler

- `gs input.gs --format js|mjs|ts -o output.<format>`.
- `--out-dir` checks and builds an entire local module graph.
- `--check` validates the graph without generating files.
- Static checks cover syntax, scopes, calls, returns, struct fields, array
  callbacks, imported types and missing exports.
- Named, namespace and default GS imports preserve type information.
- Imported structs retain nominal identity, including aliases and methods.
- TS output contains type annotations and is checked with TypeScript's strict mode.
- JS output records its ES module mode without overwriting conflicting user settings.
- Failed compilation leaves previously generated files intact.

## Assets

- Native `gs` compiler archives for the OS/CPU identified in each filename.
- `gs-v0.3.0.pyz` for Python 3.12+.
- Python wheel and source distribution for `gscript-lang` 0.3.0.
- `SHA256SUMS` for downloaded asset verification.

Native artifacts are built and exercised on Ubuntu 22.04, macOS 14 and Windows
Server 2022. Select an artifact matching your OS and CPU. The Python zipapp is
available for other platforms that provide Python 3.12+.

## Publication gates

This release is created only after all workflow gates succeed:

| Gate | Required verification |
| --- | --- |
| Language | Valid programs execute; invalid syntax, types, scopes and imports fail |
| Modules | Aliases, default exports, nominal structs and supported cycles |
| Output | JS/MJS run in Node; TS passes strict tsc and its JS runs in Node |
| Runtime matrix | Python 3.12/3.13 and Node.js 22/24 |
| Native distributions | Build and execute compiler on Linux, macOS and Windows |
| Portable distributions | Wheel install outside checkout and standalone zipapp |
| Integrity | Matching versions and SHA-256 asset checksums |

The GS 0.3 language contract is defined in `docs/language.md` and was reviewed
before compiler implementation in `docs/release-plan.md`. No known failure of a
promised release gate may be waived. Passing tests is not a guarantee against
all possible defects or behavior in unspecified environments.

# GS v0.5.0

GS自身の型検査を維持しながら、言語・出力・CLI・開発ツールを拡張しました。

- int / floatを厳密に区別。float64はfloatの別名、JS numberとの境界は明示変換で狭めます。
- print / println / printf、len、数値・文字列変換、panicを名前解決する組み込みレジストリ。
- 名前・コメントを維持する可読JS、minify、`gs .` / `gs main.gs`の簡潔なビルド。
- GSの型検査後に公式TypeScript 5.9 / 6.0 / 7.0でJSを生成する選択肢。
- JS/MJSのSource Mapと、数値ブランド付き型宣言の生成。
- lint、fmt、watch、init（node/browser/phaser）。
- DOM・Node・Worker・ECMAScriptの任意の標準型定義連携。
- 構文木・型情報・出力キャッシュの再利用、内容で検証する差分ビルド。
- 同じバージョンのVSCode / Zed / LSPは[Plugin v0.5.0](https://github.com/sofia-gros/gscript/releases/tag/plugin-v0.5.0)で配布。

## 導入・移行

[インストール](https://github.com/sofia-gros/gscript/blob/v0.5.0/docs/installation.md)と[v0.4からの移行](https://github.com/sofia-gros/gscript/blob/v0.5.0/docs/migration-v0.4-to-v0.5.md)を参照してください。既定出力はdistへのJSになりました。`gs .`は既定でminifyします。

ネイティブ版はLinux x86_64、macOS arm64、Windows x86_64。zipapp / wheelはPython 3.12以降が必要です。SHA256SUMSを同梱します。npm依存やJS実行環境は配布物へ内包しません。GS数値はJS Numberであり、その精度や外部APIの実行時値はJSの仕様に従います。

## 検証

公開前にコンパイラ・生成JS/MJS/TS・公式TS各版・外部型・Phaserのブラウザー実行を検査します。3OSでビルドした実行ファイルにも生成物の実行・異常系保護テストを実行します。計測方法と結果は[性能資料](https://github.com/sofia-gros/gscript/blob/v0.5.0/docs/performance.md)を参照してください。

# GS v0.6.0

JavaScript / TypeScriptコンパイルと、実験的なネイティブAOTバックエンドを配布します。

- GSで型検査した静的コードをC11へ下げ、Clang / GCC / Zigで機械語を生成。
- 実行ファイル・オブジェクト・静的ライブラリ・共有ライブラリ・Cヘッダーを出力。
- 固定幅整数、Cレイアウトstruct/union、固定長配列、ポインター、C/system ABI、コールバック、C文字列ビュー。
- Windows x86/x64のWin32 SDKとのサイズ・アラインメント・offset・systemコールバックの検証。
- Node.js・TypeScript・npm・Phaserの既存JS / TS経路を維持。
- CLIとLSPでbackend/nativeTarget設定を共用。ネイティブ専用構文の診断・基本編集機能を追加。
- Zed/Windowsのpercent-encoded drive URIによるdocumentSymbol失敗を修正。

## 利用

JS / TSは引き続き既定です。ネイティブ生成には対象のCツールチェーンとリンクライブラリが必要です。

```sh
gs main.gs --backend native --cc /absolute/path/to/zig -o app
gs api.gs --backend native --emit shared --header api.h -o libapi.so
```

生成したネイティブアプリにはNode.js・Python・JSエンジンは不要です。ランタイムにウィンドウや描画を組み込む構成ではなく、GSライブラリからC ABI / Win32を使って実装できます。ウィンドウ・描画ライブラリ自体は含めていません。

## 対応範囲

ネイティブは静的GSとFFIを優先する実験的機能です。generics、async、クロージャ、動的配列等は未対応です。structはCレイアウトの値型、intはint64、stringはUTF-8ビューで、JS経路との表現差を定義しています。ポインターの寿命・実際の外部ABIの一致は利用側で管理します。

配布はLinux x86_64、macOS arm64、Windows x86_64のスタンドアロンコンパイラ、Python zipapp、wheel、sdistです。SHA256SUMSを同梱します。

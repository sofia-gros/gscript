# GS v0.6.1

WindowsでGSコンパイラが起動前にVCRUNTIME140.dllの展開で終了する問題に対し、配布形式を変更します。

- WindowsはPyInstallerの単一EXE（onefile）からフォルダー形式（onedir）へ変更。起動時のDLL自己展開を不要にします。
- ZIPにはEXEと`_internal`内のPythonランタイム・DLLをすべて同梱。**EXEだけを移動せず、展開したフォルダー全体を配置してください。**
- Windows ZIPにネストしたDLLが含まれることを検査する回帰テストを追加。
- Clang・GCC・Zigのコンパイル・実行手順、PATHを使わない起動方法、Windows起動エラーの対処を追加。
- JS / TS生成、静的GSの実験的ネイティブAOTの仕様はv0.6.0と同じです。

古いgs.exeがPATHに残っている場合は、新しい配布物に置き換えた後に`Get-Command gs -All`と`gs --version`で確認します。表示は`gscript 0.6.1`です。管理アプリもソースを更新してビルドするとv0.6.1を配布版として使用します。

[インストール](https://github.com/sofia-gros/gscript/blob/v0.6.1/docs/installation.md) / [Windows起動エラー](https://github.com/sofia-gros/gscript/blob/v0.6.1/docs/windows-startup.md) / [ネイティブコンパイル](https://github.com/sofia-gros/gscript/blob/v0.6.1/docs/guide/native-build.md)

Linux x86_64、macOS arm64、Windows x86_64のコンパイラ、Python zipapp、wheel、sdistとSHA256SUMSを配布します。生成アプリはNode.js・Python・JSエンジンを必要としませんが、リンクしたライブラリ等は実行環境に必要です。

## 配布物の確認

[配布ワークフロー](https://github.com/sofia-gros/gscript/actions/runs/40212556448)が成功し、Windows上での起動を含む配布前確認を完了しました。公開ファイルのダウンロード後にもSHA256とWindows ZIP内の`_internal/VCRUNTIME140.dll`を含む構成を確認しています。実機の画面操作は別途利用環境で確認してください。

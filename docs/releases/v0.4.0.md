# GS v0.4.0

外部 JavaScript / TypeScript と既存の node_modules の型情報を、GS のコンパイル時に利用できます。

- TypeScript 5.9.3 の解決・型検査を統合。.d.ts、JSDoc、外部クラス、ジェネリクス、名前空間の型を利用。
- ローカル JS / TS と依存を js / mjs / ts に配置。型だけの import の除去、CommonJS、型宣言、tsconfig のパス別名に対応。
- Phaser 3.90.0 の実際の型定義を使い、正しい設定と API の誤用を検証。
- 内容を検証する型検査キャッシュを導入。型定義の追加・変更やパッケージ解決の変更を検出。
- GS モジュール読み込みを反復処理に変更し、1,200 モジュールのチェーンを検証。識別子集合の再利用で解析時の重複処理を削減。

外部 import の検査には Node.js 22 / 24 とプロジェクト内の TypeScript 5.9.3 が必要です。GS 単独のコンパイルには不要です。既存の .gs / .gos と出力形式を継続して使えます。

使い方、型情報の扱い、キャッシュと出力配置は [外部連携仕様](../interop.md) を参照してください。各配布物の整合性は SHA256SUMS で確認できます。

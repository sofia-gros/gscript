# GS v0.4.0

外部 JavaScript / TypeScript と既存の node_modules の型情報を、GS のコンパイル時に利用できます。

- GS自身の型検査器を拡張し、TypeScript 5.9.3から外部型のメタデータを読み込み。.d.ts、JSDoc、外部クラス、ジェネリクス、名前空間の型を利用。
- ローカル JS / TS と依存を js / mjs / ts に配置。型だけの import の除去、CommonJS、型宣言、tsconfig のパス別名に対応。
- Phaser 3.90.0 の実際の型定義を使い、正しい設定と API の誤用を検証。
- 内容を検証する型検査キャッシュを導入。型定義の追加・変更やパッケージ解決の変更を検出。
- GS モジュール読み込みを反復処理に変更し、1,200 モジュールのチェーンを検証。識別子集合の再利用で解析時の重複処理を削減。

外部 import の検査には Node.js 22 / 24 とプロジェクト内の TypeScript 5.9.3 が必要です。GS 単独のコンパイルには不要です。既存の .gs / .gos と出力形式を継続して使えます。

使い方、型情報の扱い、キャッシュと出力配置は [外部連携仕様](../interop.md) を参照してください。各配布物の整合性は SHA256SUMS で確認できます。

GSの言語機能も拡張しました。structの単一継承、constructor / super、override、構造的interface / implements、Nullable、Optional Chaining / Nullish Coalescing、Union・リテラル型、制約付きGenerics、switch・網羅性検査、static、アクセス制御・readonly、型エイリアス、enumをGS自身のパーサー・型検査器で処理します。

GSのみの拡張コードの検査・JS生成にはNode / TypeScriptは不要です。`--strict-null`で非Nullableへのnil代入を拒否できます。従来のGSコードの参照型・nilの規則は既定モードで維持します。詳しい初期化・型・実行時表現は[拡張言語仕様](../language-v0.4-extensions.md)を参照してください。

# Lint

```sh
gs lint
gs lint main.gs --json
gs lint --fix
```

GSコンパイラの型検査後に追加診断します。型エラーはGS0001/errorで終了値1、警告だけなら0です。JSONはfile/line/column/severity/code/messageを持つ配列です。行・列は1から始まります。

| コード | 内容 |
| --- | --- |
| GS1001 | 未使用変数・引数 |
| GS1002 | 未使用import |
| GS1003 | 到達不能文 |
| GS1004 | 定数条件・同一リテラル比較 |
| GS1005 | 不要な変換 |
| GS1006 | 推論型を隠すany |
| GS1007 | シャドーイング |
| GS1008 | @deprecated API |
| GS1009 | ゼロによる除算・剰余 |
| GS1012 | 行末空白 |

先頭が_の未使用名は警告しません。--fixが自動修正するのは行末空白のみです。未使用式の削除など副作用を失う修正は行いません。同じ警告を言語サーバーから表示します。
